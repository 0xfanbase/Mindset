## Accessibility and mobile (Sonnet auditor, measured)

All eight items PASS: accessible names on every control, canvas and region labels; keyboard
order figure -> toggle -> J -> B -> zoom in -> grid, visible focus ring at every stop (ring
contrast 4.61 blossom, 6.08 dark, 4.82 on the weeks card); Enter and Space toggle the stat
